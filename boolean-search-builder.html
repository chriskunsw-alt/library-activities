Keep words together with quotation marks

Without quotes, many databases search for each word separately, anywhere in the record. Quotes tell the database to find the words together, in that order.

Try it. Type a search that finds only the exact phrase climate change, then select Check.

Cover spelling differences with wildcards

A wildcard ? stands in for one letter inside a word. It is useful for Australian and American spellings, and for singular and plural forms like wom?n (woman, women).

Try it. Type one search term that finds both organisation and organization. The word list updates as you type.

Symbols differ between databases. For example, some use # or $ as well. Check the help page of the database you are searching.
